# Task Manager & Blog - Bootstrap Projects

This repository contains two beginner-level frontend projects built using **HTML** and **Bootstrap 5**:

- **1. Task Manager** – A component-based layout to learn and practice Bootstrap components.
- **2. Blog** – A simple blog-style page, and my **first full project using Bootstrap**.

---

## 📁 Project Structure

### 1. Task Manager

The **Task Manager** project was built to explore and understand Bootstrap 5 components. In this project, I learned how to use:

- Bootstrap Grid System (rows, columns)
- Cards
- Responsive layout
- Sticky headers
- Utility classes like `bg-dark`, `text-white`, etc.

### 2. Blog

This is my **first complete Bootstrap project**. It includes:

- A blog-style layout with cards
- Header with navigation
- Footer with links
- Responsive design for all screen sizes
- Dummy images and placeholder content for blog posts

---

## 🛠️ Technologies Used

- HTML5
- Bootstrap 5.3.3 (via CDN)
